# Lexi YT 420 - Portfolio

Official portfolio website of Lexi YT 420 — a professional Thumbnail Artist, Gamer, and Content Creator.

This project is a fully responsive static portfolio website built to professionally showcase creative thumbnail artwork, gaming-related designs, and visual content projects. The website focuses on clean presentation, fast loading performance, modern UI styling, SEO optimization, and secure deployment practices.

Designed with simplicity and performance in mind, the portfolio provides an organized gallery experience while maintaining lightweight assets and optimized loading across desktop and mobile devices.

---

## Overview

The purpose of this project is to create a visually appealing and professional online portfolio that highlights thumbnail design work and creator branding.

The website includes:
- A modern landing page
- Professional thumbnail showcase sections
- Dedicated works/gallery page
- Custom error pages
- Search engine optimization features
- Progressive Web App support
- Netlify security configuration
- Optimized image delivery using WebP

The portfolio is structured as a lightweight static website without any backend dependencies, making deployment simple, fast, and reliable.

## Security

The website includes multiple security-focused configurations through Netlify headers.

Implemented protections include:
- Content Security Policy (CSP)
- X-Frame-Options
- Referrer Policy
- Permissions Policy
- X-Content-Type-Options

These configurations help improve browser-level security and reduce unnecessary exposure to external resource abuse.
